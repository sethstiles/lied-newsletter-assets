# Lied Center Newsletter — Assets

Public image assets for the Lied Center staff newsletter (show promo art),
served over a CDN via jsDelivr. The newsletter itself lives in a separate
private repo. Files are organized by the month whose issue features them.

- `sep/` — September 2026 shows (featured in the August issue)

jsDelivr URL pattern:
`https://cdn.jsdelivr.net/gh/sethstiles/lied-newsletter-assets@main/<path>`
